# 큐

## 1. 큐란?

큐는 먼저 들어온 데이터가 먼저 나오는 자료구조이다. 이를 선입선출 또는 `FIFO`라고 한다. 데이터가 들어오는 쪽과 나가는 쪽이 다르기 때문에 줄을 서서 기다리는 상황과 비슷하다.

```text
들어오는 방향                         나가는 방향
    ↓                                     ↓
  [새 데이터] → [ 1 ][ 2 ][ 3 ] → 가장 먼저 들어온 1
                  앞             뒤
```

## 2. 주요 연산

| 연산 | 설명 | 일반적인 시간 복잡도 |
| --- | --- | --- |
| `enqueue` | 큐의 뒤에 데이터 추가 | `O(1)` |
| `dequeue` | 큐의 앞에서 데이터 제거 | `O(1)` |
| `front` | 큐의 가장 앞 데이터 확인 | `O(1)` |
| `is_empty` | 큐가 비어 있는지 확인 | `O(1)` |

큐의 앞에서 데이터를 꺼낸 뒤 나머지 데이터를 모두 한 칸씩 이동시키면 `O(N)`이 걸릴 수 있다. 따라서 파이썬에서는 `collections.deque`를 사용하는 것이 적합하다.

## 3. 동작 예시

`1`, `2`, `3`을 순서대로 넣고 꺼내보자.

```text
1. enqueue(1)       [1]
2. enqueue(2)       [1, 2]
3. enqueue(3)       [1, 2, 3]

4. dequeue() → 1    [2, 3]
5. dequeue() → 2    [3]
6. dequeue() → 3    []
```

가장 먼저 들어온 `1`이 가장 먼저 나오고, 가장 나중에 들어온 `3`이 가장 나중에 나온다.

## 4. 파이썬 코드 예시

```python
from collections import deque

queue = deque()

# enqueue
queue.append(1)
queue.append(2)
queue.append(3)

# front
print(queue[0])  # 1

# dequeue
print(queue.popleft())  # 1
print(queue.popleft())  # 2
print(queue.popleft())  # 3

# 비어 있는지 확인
print(not queue)  # True
```

`deque.popleft()`는 큐의 앞 데이터를 `O(1)`에 제거한다. 리스트의 `pop(0)`은 뒤의 원소들을 이동시켜야 하므로 큐 구현에는 적합하지 않다.

## 5. 큐를 활용한 문제 풀이

### 프로세스 대기열

프로세스가 실행 대기열에 들어온 순서대로 저장되고, 조건을 만족하지 못하면 다시 큐의 뒤로 들어간다.

```python
from collections import deque


def process_order(priorities, location):
    queue = deque(enumerate(priorities))
    order = 0

    while queue:
        index, priority = queue.popleft()

        if any(priority < other_priority for _, other_priority in queue):
            queue.append((index, priority))
        else:
            order += 1
            if index == location:
                return order
```

## 6. 큐의 활용 예시

- 작업 대기열 처리
- 너비 우선 탐색
- 프린터 인쇄 순서 관리
- 프로세스 실행 순서 관리
- 네트워크 요청 대기열
- 순서가 중요한 시뮬레이션

큐를 사용하면 먼저 도착한 작업을 먼저 처리해야 하는 상황을 자연스럽게 표현할 수 있다.
