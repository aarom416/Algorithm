# 힙

## 1. 힙이란?

힙은 최댓값이나 최솟값을 빠르게 꺼내기 위해 사용하는 완전 이진 트리 기반 자료구조이다.

- 최소 힙: 부모의 값이 자식의 값보다 작거나 같다.
- 최대 힙: 부모의 값이 자식의 값보다 크거나 같다.

힙은 배열로 표현할 수 있다. 인덱스가 `i`일 때 왼쪽 자식은 `2 * i + 1`, 오른쪽 자식은 `2 * i + 2`, 부모는 `(i - 1) // 2`이다.

## 2. 최소 힙 예시

```text
          1
        /   \
       3     2
      / \   /
     7   5 4
```

배열로 표현하면 `[1, 3, 2, 7, 5, 4]`이다. 가장 작은 값 `1`이 루트에 있지만, 형제 노드까지 전체적으로 정렬되어 있는 것은 아니다.

## 3. 주요 연산과 시간 복잡도

| 연산 | 설명 | 시간 복잡도 |
| --- | --- | --- |
| 삽입 | 마지막 위치에 넣고 부모와 비교하며 위로 이동 | `O(log N)` |
| 최솟값·최댓값 확인 | 루트 확인 | `O(1)` |
| 루트 삭제 | 마지막 노드를 루트로 옮긴 뒤 아래로 이동 | `O(log N)` |
| 힙 만들기 | 배열 전체를 힙 구조로 변환 | `O(N)` |

## 4. 삽입과 삭제

최소 힙 `[1, 3, 2, 7, 5, 4]`에 `0`을 삽입하면 마지막에 추가한 뒤 부모와 비교하며 위로 올라간다.

```text
처음:        [1, 3, 2, 7, 5, 4]
마지막 추가:  [1, 3, 2, 7, 5, 4, 0]
부모 2와 교환: [1, 3, 0, 7, 5, 4, 2]
부모 1과 교환: [0, 3, 1, 7, 5, 4, 2]
```

최솟값을 삭제할 때는 루트를 제거하고 마지막 노드를 루트로 옮긴 뒤, 더 작은 자식과 비교하며 아래로 내린다.

```text
삭제 전:       [1, 3, 2, 7, 5, 4]
마지막 값 이동: [4, 3, 2, 7, 5]
조정 후:       [2, 3, 4, 7, 5]
```

## 5. 파이썬 `heapq` 사용법

파이썬의 `heapq` 모듈은 최소 힙을 제공한다.

```python
import heapq

heap = []
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)

print(heap[0])              # 1
print(heapq.heappop(heap))  # 1
print(heapq.heappop(heap))  # 2
```

기존 리스트를 힙으로 바꿀 때는 `heapify`를 사용한다.

```python
numbers = [5, 2, 8, 1, 3]
heapq.heapify(numbers)
print(heapq.heappop(numbers))  # 1
```

## 6. 최대 힙

`heapq`는 최소 힙만 제공하므로 값에 음수를 붙여 최대 힙처럼 사용할 수 있다.

```python
import heapq

max_heap = []
for number in [3, 1, 5, 2]:
    heapq.heappush(max_heap, -number)

print(-heapq.heappop(max_heap))  # 5
print(-heapq.heappop(max_heap))  # 3
```

튜플을 넣으면 첫 번째 원소를 우선순위로 사용한다.

```python
heap = []
heapq.heappush(heap, (2, "작업 B"))
heapq.heappush(heap, (1, "작업 A"))
print(heapq.heappop(heap))  # (1, '작업 A')
```

## 7. 우선순위 큐

우선순위 큐는 들어온 순서가 아니라 우선순위가 높은 데이터부터 처리하는 자료구조이다. 힙으로 구현하면 삽입과 삭제를 `O(log N)`에 처리할 수 있다.

```python
import heapq

tasks = []
heapq.heappush(tasks, (3, "낮은 우선순위"))
heapq.heappush(tasks, (1, "높은 우선순위"))

priority, task = heapq.heappop(tasks)
print(task)  # 높은 우선순위
```

## 8. 힙과 정렬의 차이

모든 데이터를 순서대로 배치하려면 정렬이 적합하다. 최솟값이나 최댓값만 반복해서 꺼내려면 힙이 적합하다.

| 상황 | 적합한 방법 |
| --- | --- |
| 모든 값을 순서대로 확인 | 정렬 |
| 최솟값·최댓값을 반복해서 꺼냄 | 힙 |
| 상위 몇 개 값만 필요 | 힙 또는 부분 정렬 |
| 우선순위가 바뀌며 작업 처리 | 우선순위 큐 |
