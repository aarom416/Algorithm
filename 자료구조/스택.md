# 스택

## 1. 스택이란?

스택은 데이터를 한쪽 끝에서만 넣고 뺄 수 있는 자료구조이다. 가장 나중에 들어온 데이터가 가장 먼저 나오는 구조이며, 이를 후입선출 또는 `LIFO`라고 한다.

```text
나중에 들어온 데이터가 먼저 나감
          ↓
       ┌─────┐
       │  3  │ ← pop
       ├─────┤
       │  2  │
       ├─────┤
       │  1  │
       └─────┘
          ↑
        push
```

가장 위에 있는 데이터를 스택의 꼭대기라고 한다.

## 2. 주요 연산

| 연산 | 설명 | 일반적인 시간 복잡도 |
| --- | --- | --- |
| `push` | 데이터를 스택의 꼭대기에 추가 | `O(1)` |
| `pop` | 꼭대기의 데이터를 꺼내고 삭제 | `O(1)` |
| `peek` | 꼭대기의 데이터를 확인만 함 | `O(1)` |
| `is_empty` | 스택이 비어 있는지 확인 | `O(1)` |

스택 내부의 특정 값을 찾거나 중간 값을 확인하려면 처음부터 순서대로 확인해야 하므로 `O(N)`이 걸릴 수 있다.

## 3. 동작 예시

빈 스택에 `1`, `2`, `3`을 순서대로 넣어보자.

```text
1. push(1)       2. push(2)       3. push(3)

   ┌───┐             ┌───┐             ┌───┐
   │ 1 │             │ 2 │             │ 3 │ ← 가장 먼저 pop
   └───┘             ├───┤             ├───┤
                     │ 1 │             │ 2 │
                     └───┘             ├───┤
                                       │ 1 │
                                       └───┘
```

이 상태에서 `pop`을 세 번 실행하면 `3 → 2 → 1` 순서로 나온다.

```text
pop() → 3
pop() → 2
pop() → 1
```

## 4. 파이썬 코드 예시

파이썬에서는 리스트의 `append`를 `push`, `pop`을 `pop`처럼 사용할 수 있다.

```python
stack = []

# push
stack.append(1)
stack.append(2)
stack.append(3)

# peek
print(stack[-1])  # 3

# pop
print(stack.pop())  # 3
print(stack.pop())  # 2
print(stack.pop())  # 1

# 비어 있는지 확인
print(len(stack) == 0)  # True
```

스택이 비어 있을 때 `pop`을 실행하면 오류가 발생할 수 있으므로, 꺼내기 전에 비어 있는지 확인하는 습관이 필요하다.

## 5. 스택을 활용한 괄호 검사

여는 괄호를 스택에 넣고, 닫는 괄호가 나오면 가장 최근에 넣은 여는 괄호와 짝이 맞는지 확인할 수 있다.

```python
def is_valid_parentheses(text):
    stack = []

    for character in text:
        if character == "(":
            stack.append(character)
        elif character == ")":
            if not stack:
                return False
            stack.pop()

    return not stack


print(is_valid_parentheses("(()())"))  # True
print(is_valid_parentheses("(()"))     # False
```

문자열을 한 번 순회하므로 시간 복잡도는 `O(N)`, 최악의 경우 괄호를 모두 저장하므로 공간 복잡도는 `O(N)`이다.

## 6. 스택을 활용하는 상황

- 괄호의 짝 검사
- 실행 취소와 다시 실행
- 웹 브라우저 방문 기록 뒤로 가기
- 재귀 호출 과정 관리
- 깊이 우선 탐색
- 후위 표기식 계산
