# 플로이드 워셜

## 1. 플로이드 워셜이란?

플로이드 워셜은 **동적 계획법을 이용해 모든 정점 쌍 사이의 최단 거리를 구하는 그래프 알고리즘**이다. 한 출발점에서 모든 정점까지가 아니라, 모든 출발점과 도착점 조합의 최단 거리를 구할 때 사용한다.

핵심은 중간 정점 `k`를 하나씩 허용하며 다음 두 경로를 비교하는 것이다.

```text
i에서 j로 바로 가는 기존 거리
i에서 k를 거쳐 j로 가는 거리
```

둘 중 더 짧은 값을 거리 표에 저장한다.

## 2. 왜 사용하는가?

다익스트라는 한 출발점에서 다른 모든 정점까지의 최단 거리를 구한다. 모든 정점을 출발점으로 삼아야 한다면 다익스트라를 여러 번 실행해야 하지만, 플로이드 워셜은 모든 결과를 하나의 `distance` 표에 저장하며 갱신한다.

| 상황 | 적합한 알고리즘 |
|---|---|
| 한 출발점에서 모든 정점까지 | 다익스트라 |
| 모든 정점 쌍 사이의 최단 거리 | 플로이드 워셜 |
| 음수 간선이 있는 한 출발점 최단 거리 | 벨만-포드 |

플로이드 워셜은 구현이 단순하고 모든 쌍의 결과를 바로 조회할 수 있지만, 시간 복잡도가 `O(V^3)`이므로 정점 수가 작을 때 적합하다.

## 3. 어떤 문제에서 의심해야 할까?

- 모든 도시에서 모든 도시로 이동하는 최소 비용을 구한다.
- 모든 정점 쌍의 최단 거리를 출력한다.
- 여러 출발점과 도착점의 최단 거리 질문에 반복해서 답한다.
- 정점 수 `V`가 작아 `V × V` 거리 표를 만들 수 있다.
- 특정 정점을 중간에 거쳐 갈 수 있게 하며 결과를 갱신한다.

## 4. 예시: 중간 정점 2번 사용하기

다음 그래프가 있다고 하자.

```text
1 --4--> 2 --1--> 3
 \----------------> 3 (비용 10)
```

처음에는 `1 → 3`의 거리가 `10`이다. 하지만 2번을 중간 정점으로 허용하면 다음 경로가 생긴다.

```text
1 → 2 → 3 = 4 + 1 = 5
```

따라서 `distance[1][3]`을 `10`에서 `5`로 바꾼다.

## 5. 점화식

```text
distance[i][j] = min(
    distance[i][j],
    distance[i][k] + distance[k][j]
)
```

자연어로 읽으면 다음과 같다.

> i에서 j로 바로 가는 기존 경로와 i에서 k를 거쳐 j로 가는 새 경로 중 더 짧은 값을 저장한다.

예시:

```text
distance[1][3] = min(10, distance[1][2] + distance[2][3])
                = min(10, 4 + 1)
                = 5
```

## 6. 거리 표 갱신

초기 표는 다음과 같다. `∞`는 아직 연결되지 않았다는 뜻이다.

```text
      1    2    3
1     0    4   10
2     ∞    0    1
3     ∞    ∞    0
```

2번을 중간 정점으로 확인하면 `1 → 2 → 3`을 비교한다.

```text
기존 거리: 1 → 3 = 10
새 거리:   1 → 2 → 3 = 4 + 1 = 5
갱신 결과: 1 → 3 = 5
```

```text
      1    2    3
1     0    4    5
2     ∞    0    1
3     ∞    ∞    0
```

## 7. Java 구현

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int n = 3;
        int INF = 1_000_000_000; // 연결되지 않은 상태를 나타내는 큰 값

        int[][] distance = {
            {0, 4, 10},
            {INF, 0, 1},
            {INF, INF, 0}
        };

        for (int k = 0; k < n; k++) { // k번 정점을 중간 정점으로 허용한다.
            for (int i = 0; i < n; i++) { // 출발 정점
                for (int j = 0; j < n; j++) { // 도착 정점
                    distance[i][j] = Math.min(
                        distance[i][j],
                        distance[i][k] + distance[k][j]
                    ); // 기존 경로와 k를 거치는 경로 중 작은 값을 저장한다.
                }
            }
        }

        for (int[] row : distance) {
            System.out.println(Arrays.toString(row));
        }

        // 출력:
        // [0, 4, 5]
        // [1000000000, 0, 1]
        // [1000000000, 1000000000, 0]
    }
}
```

## 8. 반복문 순서가 중요한 이유

```java
for (int k = 0; k < n; k++) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            // i에서 j까지, k를 거치는 것이 더 짧은지 확인한다.
        }
    }
}
```

가장 바깥의 `k`는 “이번 단계에서 중간에 사용할 정점”이다. 따라서 `k → i → j` 순서를 지켜야 중간 정점을 단계적으로 추가할 수 있다.

## 9. 복잡도와 주의점

- 시간 복잡도: `O(V^3)`
- 공간 복잡도: `O(V^2)`
- 자기 자신으로 가는 거리는 `0`으로 초기화한다.
- 연결되지 않은 간선은 큰 값 `INF`로 초기화한다.
- `INF + INF`가 정수 범위를 넘지 않도록 한다.
- 음수 간선은 가능하지만 음수 사이클이 있으면 최단 거리가 정의되지 않는다.
- 무방향 그래프는 양방향 간선을 모두 추가한다.
