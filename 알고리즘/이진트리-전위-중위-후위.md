# 이진트리 (전위, 중위, 후위)

## 1. 이진트리란?

이진트리는 하나의 노드가 최대 두 개의 자식 노드를 가지는 트리 자료구조이다. 왼쪽 자식과 오른쪽 자식을 구분하며, 자식이 없을 수도 있다.

### 배열로 표현하기

완전 이진트리를 배열로 표현하면 다음 규칙을 사용할 수 있다. 인덱스는 0부터 시작한다.

- 현재 노드: `i`
- 왼쪽 자식: `2 * i + 1`
- 오른쪽 자식: `2 * i + 2`
- 부모 노드: `(i - 1) // 2`

일반적인 순회는 모든 노드를 한 번씩 방문하므로 시간 복잡도는 `O(N)`이다. 재귀 호출에 사용하는 공간 복잡도는 트리의 높이를 `H`라고 할 때 `O(H)`이다. 균형 잡힌 트리는 `H = O(log N)`, 한쪽으로 치우친 트리는 `H = O(N)`이다.

## 2. 순회 순서

다음 트리를 기준으로 순회한다.

```text
        A
       / \
      B   C
     / \
    D   E
```

### 전위 순회

방문 순서는 **현재 노드 → 왼쪽 서브트리 → 오른쪽 서브트리**이다.

```text
A → B → D → E → C
```

루트 노드를 먼저 처리해야 하는 경우에 사용한다.

### 중위 순회

방문 순서는 **왼쪽 서브트리 → 현재 노드 → 오른쪽 서브트리**이다.

```text
D → B → E → A → C
```

이진 탐색 트리에서는 중위 순회 결과가 정렬된 순서가 된다.

### 후위 순회

방문 순서는 **왼쪽 서브트리 → 오른쪽 서브트리 → 현재 노드**이다.

```text
D → E → B → C → A
```

자식 노드를 먼저 처리한 뒤 현재 노드를 처리해야 하는 경우에 사용한다.

## 3. 파이썬 코드 예시

```python
tree = ["A", "B", "C", "D", "E"]


def preorder(index, result):
    if index >= len(tree):
        return

    result.append(tree[index])
    preorder(index * 2 + 1, result)
    preorder(index * 2 + 2, result)


def inorder(index, result):
    if index >= len(tree):
        return

    inorder(index * 2 + 1, result)
    result.append(tree[index])
    inorder(index * 2 + 2, result)


def postorder(index, result):
    if index >= len(tree):
        return

    postorder(index * 2 + 1, result)
    postorder(index * 2 + 2, result)
    result.append(tree[index])


preorder_result = []
inorder_result = []
postorder_result = []

preorder(0, preorder_result)
inorder(0, inorder_result)
postorder(0, postorder_result)

print(preorder_result)   # ['A', 'B', 'D', 'E', 'C']
print(inorder_result)    # ['D', 'B', 'E', 'A', 'C']
print(postorder_result)  # ['D', 'E', 'B', 'C', 'A']
```

핵심은 재귀 호출의 위치이다.

- 현재 노드를 `append`한 뒤 재귀 호출하면 전위 순회
- 왼쪽 재귀 호출과 오른쪽 재귀 호출 사이에 `append`하면 중위 순회
- 두 재귀 호출이 끝난 뒤 `append`하면 후위 순회
