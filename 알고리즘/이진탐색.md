# 이진 탐색

## 1. 이진 탐색이란?

이진 탐색은 정렬된 자료에서 원하는 값을 찾는 알고리즘이다. 탐색 범위의 가운데 값을 확인한 뒤, 찾는 값이 더 작으면 왼쪽 범위만 남기고 더 크면 오른쪽 범위만 남긴다. 한 번 비교할 때마다 탐색 범위가 절반으로 줄어든다.

따라서 정렬된 배열의 원소 개수를 `N`이라고 하면 시간 복잡도는 `O(log N)`이다. `start`, `end`, `mid` 변수를 사용하는 반복문은 추가 공간을 거의 사용하므로 공간 복잡도는 `O(1)`이다.

단, 이진 탐색을 사용하려면 자료가 정렬되어 있어야 한다.

## 2. `start`, `mid`, `end`로 이해하기

다음 배열에서 `11`을 찾아보자.

```text
인덱스:  0   1   2   3   4   5   6   7
값:     [1,  3,  5,  7,  9, 11, 13, 15]
```

### 1단계

처음에는 배열 전체를 탐색한다.

```text
start = 0
end   = 7
mid   = (start + end) // 2 = 3
```

현재 포인터의 위치를 배열 아래에 표시하면 다음과 같다.

```text
인덱스:  0   1   2   3   4   5   6   7
값:     [1,  3,  5,  7,  9, 11, 13, 15]
         ↑           ↑                   ↑
       start        mid                 end
```

- `start`는 탐색 범위의 시작인 인덱스 `0`을 가리킨다.
- `mid`는 `start`와 `end`의 중간인 인덱스 `3`을 가리킨다.
- `end`는 탐색 범위의 끝인 인덱스 `7`을 가리킨다.
- `mid` 위치의 값은 `7`이다.

찾는 값 `11`이 `7`보다 크므로 인덱스 `0`부터 `3`까지는 더 이상 탐색할 필요가 없다. 따라서 `start`를 `mid + 1`인 `4`로 이동한다.

```text
인덱스:  0   1   2   3   4   5   6   7
값:     [1,  3,  5,  7,  9, 11, 13, 15]
                             ↑       ↑
                           start    end
```

### 2단계

```text
start = 4
end   = 7
mid   = (4 + 7) // 2 = 5
```

`mid` 위치의 값이 `11`이므로 찾는 값과 일치한다.

```text
인덱스:              4    5    6    7
값:                 [9,  11,  13, 15]
                   start mid       end
```

찾는 값이 `mid`보다 작으면 `end = mid - 1`, 크면 `start = mid + 1`로 갱신한다.

## 3. 파이썬 코드 예시

```python
def binary_search(numbers, target):
    start = 0
    end = len(numbers) - 1

    while start <= end:
        mid = (start + end) // 2

        if numbers[mid] == target:
            return mid
        if numbers[mid] < target:
            start = mid + 1
        else:
            end = mid - 1

    return -1


numbers = [1, 3, 5, 7, 9, 11, 13, 15]
print(binary_search(numbers, 11))  # 5
print(binary_search(numbers, 6))   # -1
```

## 4. `bisect_left`와 `bisect_right`

파이썬의 `bisect` 모듈은 정렬된 배열에서 삽입 위치를 이진 탐색으로 찾아준다.

```python
from bisect import bisect_left, bisect_right

numbers = [1, 2, 2, 2, 4]
target = 2

print(bisect_left(numbers, target))   # 1
print(bisect_right(numbers, target))  # 4
```

```text
인덱스:  0   1   2   3   4
값:     [1,  2,  2,  2,  4]
             ↑           ↑
       bisect_left  bisect_right
```

### `bisect_left`

`target` 이상인 값이 처음 나타나는 위치를 반환한다. 즉, 같은 값이 여러 개 있으면 가장 왼쪽 위치를 찾는다.

```text
bisect_left([1, 2, 2, 2, 4], 2) = 1
```

### `bisect_right`

`target`보다 큰 값이 처음 나타나는 위치를 반환한다. 즉, 같은 값이 여러 개 있으면 가장 오른쪽 값의 다음 위치를 찾는다.

```text
bisect_right([1, 2, 2, 2, 4], 2) = 4
```

따라서 특정 값의 개수는 다음처럼 구할 수 있다.

```python
count = bisect_right(numbers, target) - bisect_left(numbers, target)
print(count)  # 3
```

두 함수 모두 시간 복잡도는 `O(log N)`이다.

## 5. 자주 하는 실수

- 정렬되지 않은 배열에 이진 탐색을 적용하는 경우
- `start`와 `end`를 갱신할 때 `mid`를 다시 포함해 무한 반복이 발생하는 경우
- `while start < end`와 `while start <= end`의 종료 조건을 문제에 맞게 선택하지 않는 경우
- `mid`를 계산할 때 정수 나눗셈을 사용하지 않는 경우
