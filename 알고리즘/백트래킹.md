# 백트래킹

## 1. 백트래킹이란?

백트래킹은 가능한 선택을 하나씩 시도하면서 조건에 맞지 않는 경로를 발견하면 즉시 이전 상태로 돌아가 다른 선택을 시도하는 탐색 방법이다.

모든 경우를 끝까지 확인하는 완전 탐색과 비슷하지만, 정답이 될 수 없는 경로를 중간에 포기한다는 점이 다르다. 이처럼 더 이상 탐색할 필요가 없는 가지를 잘라내는 것을 가지치기라고 한다.

백트래킹은 보통 다음 세 단계로 구성된다.

1. 현재 위치에서 선택할 수 있는 값을 고른다.
2. 선택한 값을 상태에 반영하고 재귀 호출한다.
3. 재귀 호출이 끝나면 선택을 취소해 이전 상태로 되돌린다.

탐색 가능한 선택의 수를 `B`, 탐색 깊이를 `D`라고 하면 최악의 시간 복잡도는 일반적으로 `O(B^D)`이다. 재귀 호출과 현재 선택 상태를 저장하는 공간 복잡도는 `O(D)`이다. 실제 실행 시간은 조건 검사와 가지치기의 정도에 따라 크게 달라진다.

## 2. 선택과 되돌리기 예시

숫자 `[1, 2, 3]`에서 숫자 2개를 순서 없이 고르는 과정을 생각해보자.

```text
시작
├─ 1 선택
│  ├─ 2 선택 → [1, 2] 완성
│  └─ 3 선택 → [1, 3] 완성
├─ 2 선택
│  └─ 3 선택 → [2, 3] 완성
└─ 3 선택
   └─ 선택할 수 있는 다음 숫자가 없음
```

각 경로에서 다음 순서로 동작한다.

```text
선택 → 재귀 호출 → 결과 확인 → 선택 취소 → 다음 선택
```

예를 들어 `[1, 2]`를 완성한 뒤에는 마지막에 선택한 `2`를 취소한다. 그러면 `[1]` 상태로 돌아가 `3`을 선택해 `[1, 3]`을 만들 수 있다.

## 3. 파이썬 코드 예시

```python
def combinations(numbers, count):
    answer = []
    selected = []

    def backtrack(start):
        if len(selected) == count:
            answer.append(selected[:])
            return

        for index in range(start, len(numbers)):
            selected.append(numbers[index])  # 선택
            backtrack(index + 1)             # 다음 선택
            selected.pop()                   # 선택 취소

    backtrack(0)
    return answer


print(combinations([1, 2, 3], 2))
# [[1, 2], [1, 3], [2, 3]]
```

`selected.pop()`이 백트래킹의 핵심이다. 재귀 호출이 끝난 뒤 이전 상태로 되돌려야 같은 자료를 사용해 다른 경우를 탐색할 수 있다.

## 4. 가지치기

모든 경우를 끝까지 탐색하지 않고, 현재 상태가 조건을 만족할 가능성이 없으면 재귀 호출을 중단한다.

```python
def search(current_sum, target, numbers, index):
    if current_sum > target:
        return  # target을 초과했으므로 가지치기

    if current_sum == target:
        return  # 정답을 찾았으므로 종료

    for next_index in range(index, len(numbers)):
        search(
            current_sum + numbers[next_index],
            target,
            numbers,
            next_index + 1,
        )
```

문제의 조건에 따라 중복 선택 방지, 합계 초과 여부, 방문 여부 등을 검사하면 탐색해야 할 경로를 줄일 수 있다.

## 5. 백트래킹 문제를 볼 때 확인할 것

- 현재 선택 상태를 어떻게 표현할 것인가?
- 다음 단계에서 선택할 수 있는 후보는 무엇인가?
- 정답을 완성한 시점은 언제인가?
- 더 이상 정답이 될 수 없는 상태를 어떻게 판단할 것인가?
- 재귀 호출이 끝난 뒤 어떤 값을 원래대로 되돌려야 하는가?
