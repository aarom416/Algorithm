# 파이썬 기본 문법

코딩 테스트에서 자주 사용하는 파이썬 문법과 표준 라이브러리를 한곳에 정리한 문서이다.

## 1. 입력과 출력

### 기본 입력

```python
name = input()
number = int(input())
numbers = list(map(int, input().split()))
```

`input().split()`은 공백으로 문자열을 나누고, `map(int, ...)`는 각 값을 정수로 변환한다.

```python
n, m = map(int, input().split())
```

### 빠른 입력

입력이 많은 문제에서는 `sys.stdin.readline`을 사용한다.

```python
import sys

input = sys.stdin.readline
n = int(input())
numbers = list(map(int, input().split()))
```

문자열 끝의 줄바꿈이 필요하지 않으면 `strip()`을 사용할 수 있다.

```python
text = input().strip()
```

### 출력

```python
print(10)
print("hello", "python")
print(1, 2, 3, sep="-")       # 1-2-3
print("hello", end=" ")
```

리스트의 값을 한 줄에 출력할 때는 `join`을 자주 사용한다.

```python
numbers = [1, 2, 3]
print(*numbers)                 # 1 2 3
print(" ".join(map(str, numbers)))
```

### 산술 연산


```python

```

## 4. 반복문

### `for`와 `range`

```python
for i in range(5):
    print(i)            # 0, 1, 2, 3, 4

for i in range(2, 6):
    print(i)            # 2, 3, 4, 5

for i in range(10, 0, -2):
    print(i)            # 10, 8, 6, 4, 2
```

`range(start, end, step)`에서 `end`는 포함되지 않는다.

### `while`

```python
count = 0
while count < 5:
    count += 1
```

### `break`와 `continue`

```python
for number in numbers:
    if number == target:
        break          # 반복문 종료
    if number < 0:
        continue       # 다음 반복으로 이동
```

### `for ... else`

반복문이 `break` 없이 끝났을 때 `else`가 실행된다.

```python
for number in numbers:
    if number == target:
        print("찾음")
        break
else:
    print("못 찾음")
```

## 5. 리스트

```python
numbers = [3, 1, 4]

numbers.append(5)       # 뒤에 추가
numbers.insert(1, 10)   # 인덱스 1에 추가
numbers.pop()           # 마지막 값 삭제 후 반환
numbers.pop(0)          # 인덱스 0 삭제
numbers.remove(4)      # 값 4를 처음 만난 위치에서 삭제
numbers.sort()          # 오름차순 정렬
numbers.reverse()       # 순서 뒤집기
```

자주 사용하는 함수:

```python
len(numbers)
sum(numbers)
min(numbers)
max(numbers)
numbers.count(1)
numbers.index(3)
```

### 리스트 슬라이싱

```python
numbers[start:end]       # end 직전까지
numbers[:3]              # 처음부터 인덱스 2까지
numbers[2:]              # 인덱스 2부터 끝까지
numbers[::2]             # 두 칸씩
numbers[::-1]            # 역순
```

### 리스트 복사 주의

```python
copied = numbers[:]
copied = list(numbers)
```

`copied = numbers`는 같은 리스트를 가리키므로 한쪽을 수정하면 다른 쪽도 바뀐다.

### 리스트 컴프리헨션

```python
squares = [x * x for x in range(5)]
even_numbers = [x for x in numbers if x % 2 == 0]
matrix = [[0] * 3 for _ in range(4)]
```

2차원 리스트를 만들 때 `[[0] * 3] * 4`를 사용하면 같은 행을 공유하므로 주의한다.

## 7. 딕셔너리

딕셔너리는 키와 값을 저장한다. 평균적으로 삽입, 삭제, 조회가 `O(1)`이다.

```python
counter = {}
counter["apple"] = 2
counter["banana"] = 3

print(counter["apple"])
print(counter.get("orange", 0))
print("apple" in counter)
```

```python
for key in counter:
    print(key)

for key, value in counter.items():
    print(key, value)

keys = list(counter.keys())
values = list(counter.values())
```

### 빈도수 세기

```python
counter = {}
for value in numbers:
    counter[value] = counter.get(value, 0) + 1
```

## 8. 집합

집합은 중복을 허용하지 않는다.

```python
visited = set()
visited.add(1)
visited.add(2)
visited.discard(3)       # 없어도 오류 없음

if 1 in visited:
    print("방문함")
```

집합 연산:

```python
set_a | set_b    # 합집합
set_a & set_b    # 교집합
set_a - set_b    # 차집합
set_a ^ set_b    # 대칭 차집합
```

## 9. 튜플과 언패킹

튜플은 수정할 수 없는 순서 자료형이다.

```python
point = (3, 4)
x, y = point

a, b = 1, 2
a, b = b, a
```

반복문에서 인덱스와 값을 함께 사용할 때 `enumerate`를 사용한다.

```python
for index, value in enumerate(numbers):
    print(index, value)
```

두 리스트를 동시에 순회할 때 `zip`을 사용한다.

```python
names = ["철수", "영희"]
scores = [80, 90]

for name, score in zip(names, scores):
    print(name, score)
```

## 10. 정렬

```python
numbers.sort()                  # 원본 변경
sorted_numbers = sorted(numbers) # 새 리스트 반환
numbers.sort(reverse=True)
```

### `key`와 람다

```python
words = ["apple", "kiwi", "banana"]
words.sort(key=len)

students = [("철수", 90), ("영희", 80), ("민수", 90)]
students.sort(key=lambda student: student[1])
students.sort(key=lambda student: (-student[1], student[0]))
```

정렬은 일반적으로 `O(N log N)`이다. 여러 기준을 정렬할 때는 튜플의 우선순위와 부호를 활용할 수 있다.

## 11. `any`, `all`, `map`, `filter`, `reduce`

```python
any([False, True, False])   # 하나라도 참이면 True
all([True, True, False])    # 모두 참일 때만 True

numbers = list(map(int, ["1", "2", "3"]))
even = list(filter(lambda x: x % 2 == 0, numbers))
```

`reduce`는 여러 값을 누적해서 하나의 값으로 만든다.


## 12. `collections` 모듈

### `deque`

양쪽 끝에서 `O(1)`에 추가·삭제할 수 있다.

```python
from collections import deque

queue = deque([1, 2, 3])
queue.append(4)
queue.appendleft(0)
queue.pop()
queue.popleft()
```

### `Counter`

값의 빈도수를 쉽게 계산한다.

```python
from collections import Counter

counter = Counter("banana")
print(counter["a"])
print(counter.most_common(2))
```

### `defaultdict`

존재하지 않는 키의 기본값을 자동으로 만든다.

```python
from collections import defaultdict

graph = defaultdict(list)
graph[1].append(2)
graph[2].append(3)
```

## 13. `heapq` 우선순위 큐

파이썬의 `heapq`는 최소 힙이다. 가장 작은 값이 먼저 나온다.

```python
import heapq

heap = []
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)

print(heapq.heappop(heap))  # 1
```

기존 리스트를 한 번에 힙으로 만들려면 `heapify`를 사용한다.

```python
heap = [5, 1, 4, 2]
heapq.heapify(heap)
```

최대 힙은 값에 음수를 붙여 구현한다.

```python
max_heap = []
heapq.heappush(max_heap, -10)
heapq.heappush(max_heap, -3)
print(-heapq.heappop(max_heap))  # 10
```

삽입과 삭제는 `O(log N)`, 최솟값 확인은 `O(1)`이다.

## 14. `bisect` 이진 탐색

정렬된 리스트에서 삽입 위치를 찾는다.

```python
from bisect import bisect_left, bisect_right

numbers = [1, 2, 2, 2, 4]
print(bisect_left(numbers, 2))   # 1
print(bisect_right(numbers, 2))  # 4
```

특정 값의 개수는 다음처럼 구할 수 있다.

```python
count = bisect_right(numbers, 2) - bisect_left(numbers, 2)
```

두 함수의 시간 복잡도는 `O(log N)`이다.

## 15. `itertools`

### 순열과 조합

```python
from itertools import permutations, combinations

list(permutations([1, 2, 3], 2))
list(combinations([1, 2, 3], 2))
```

### 중복 순열과 중복 조합

```python
from itertools import product, combinations_with_replacement

list(product([1, 2], repeat=2))
list(combinations_with_replacement([1, 2, 3], 2))
```

### 누적 합

```python
from itertools import accumulate

print(list(accumulate([1, 2, 3, 4])))  # [1, 3, 6, 10]
```

## 16. 수학 함수

```python
import math

math.gcd(12, 18)       # 최대공약수
math.lcm(12, 18)       # 최소공배수
math.sqrt(16)          # 제곱근
math.factorial(5)      # 팩토리얼
math.ceil(3.2)         # 올림
math.floor(3.8)        # 내림
math.inf               # 무한대
```

최소공배수는 다음처럼 직접 구할 수도 있다.

```python
def lcm(a, b):
    return a * b // math.gcd(a, b)
```

## 17. 함수와 재귀

```python
def add(a, b=0):
    return a + b


def total(*numbers):
    return sum(numbers)


def print_info(**kwargs):
    for key, value in kwargs.items():
        print(key, value)
```

재귀 함수는 종료 조건이 반드시 필요하다.

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
```

재귀 깊이가 깊어질 수 있는 문제에서는 다음 설정을 고려한다.

```python
import sys

sys.setrecursionlimit(10**6)
```

## 18. 인덱스와 참조 주의사항

```python
numbers = [1, 2, 3]

for number in numbers:
    number += 1       # 원본 리스트는 바뀌지 않음

for index in range(len(numbers)):
    numbers[index] += 1
```

2차원 리스트는 다음처럼 생성해야 각 행이 독립적으로 동작한다.

```python
board = [[0] * 5 for _ in range(5)]
```
