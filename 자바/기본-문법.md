# 자바 기본 문법

코딩 테스트에서 자주 사용하는 자바 문법과 표준 라이브러리를 정리한 문서이다.

## 1. 기본 구조와 입력

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 한 줄을 입력받아 문자열로 저장한다.
        System.out.println("Hello, Java");
        // 출력: Hello, Java
    }
}
```

```java
int n = Integer.parseInt(br.readLine());
StringTokenizer st = new StringTokenizer(br.readLine());
int a = Integer.parseInt(st.nextToken());
int b = Integer.parseInt(st.nextToken());
// 입력 예시: 3 5
// 결과: n은 첫째 줄의 정수, a는 3, b는 5
```

입력이 많으면 `BufferedReader`와 `StringTokenizer`를 사용한다.

```java
static class FastScanner {
    private final BufferedInputStream input = new BufferedInputStream(System.in);

    int nextInt() throws IOException {
        int c;
        do c = input.read(); while (c <= ' ');
        int sign = 1;
        if (c == '-') {
            sign = -1;
            c = input.read();
        }
        int value = 0;
        while (c > ' ') {
            value = value * 10 + c - '0';
            c = input.read();
        }
        return value * sign;
    }
}
```

## 7. `HashMap`과 `HashSet`

```java
Map<String, Integer> count = new HashMap<>();
count.put("apple", 2);                 // 키 apple에 값 2 저장
count.get("apple");                    // 키 apple의 값 조회
count.getOrDefault("orange", 0);       // 없으면 기본값 0 반환
count.containsKey("apple");            // 키 존재 여부 확인
count.remove("apple");                 // 키와 값 삭제
// 키 "apple"에 값 2를 저장하고, get으로 조회한다.
// getOrDefault는 키가 없을 때 기본값 0을 반환한다.
```

```java
for (String word : words) {
    count.put(word, count.getOrDefault(word, 0) + 1);
}

for (Map.Entry<String, Integer> entry : count.entrySet()) {
    System.out.println(entry.getKey() + " " + entry.getValue());
}
```

```java
Set<Integer> visited = new HashSet<>();
visited.add(1);                         // 값 추가
visited.remove(1);                      // 값 삭제
boolean checked = visited.contains(2);  // 값 존재 여부 확인
// 집합은 같은 값을 한 번만 저장하므로 방문 여부를 빠르게 확인할 수 있다.
```

`HashMap`과 `HashSet`의 평균적인 추가·삭제·검색은 `O(1)`이다.

## 9. 우선순위 큐

`PriorityQueue`는 기본적으로 최소 힙이다.

```java
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
minHeap.offer(3);                       // 힙에 값 추가
minHeap.offer(1);                       // 힙에 값 추가
minHeap.offer(2);                       // 힙에 값 추가
System.out.println(minHeap.peek());     // 최솟값 확인, 출력: 1
System.out.println(minHeap.poll());     // 최솟값 제거, 출력: 1
// 출력: peek는 1, 첫 번째 poll도 1이다.
```

최대 힙은 내림차순 비교자를 사용한다.

```java
PriorityQueue<Integer> maxHeap =
    new PriorityQueue<>(Collections.reverseOrder());
maxHeap.offer(3);                       // 힙에 값 추가
maxHeap.offer(1);                       // 힙에 값 추가
System.out.println(maxHeap.poll());     // 최댓값 제거, 출력: 3
// 출력: 3, 가장 큰 값부터 나온다.
```

## 10. 정렬과 비교자

```java
Arrays.sort(numbers); // 기본형 배열을 오름차순 정렬
int[][] jobs = {{3, 10}, {1, 5}, {2, 7}};
Arrays.sort(jobs, (a, b) -> Integer.compare(a[0], b[0]));
// 각 배열의 0번째 값을 기준으로 오름차순 정렬
```

여러 기준 정렬:

```java
Arrays.sort(jobs, (a, b) -> {
    if (a[0] != b[0]) return Integer.compare(a[0], b[0]);
    return Integer.compare(a[1], b[1]);
});
```

문자열 길이와 사전순 정렬:

```java
Arrays.sort(words, (a, b) -> {
    if (a.length() != b.length()) {
        return Integer.compare(a.length(), b.length());
    }
    return a.compareTo(b);
});
```

`a - b`는 큰 정수에서 오버플로가 발생할 수 있으므로 `Integer.compare`가 안전하다.

### 배열과 리스트 변환

```java
int[] array = {1, 2, 3};

    .boxed()

## 15. 자바에서 특히 주의할 점

- 문자열 비교는 `==`가 아니라 `equals`를 사용한다.
- `int` 범위를 넘을 수 있는 계산은 `long`으로 시작한다.
- `ArrayList<Integer>.remove(1)`은 값 1이 아니라 인덱스 1을 삭제한다.
- `Arrays.asList`는 크기 변경이 불가능하다.
- `PriorityQueue`는 전체가 정렬된 상태가 아니라 최상위 우선순위만 보장한다.
- `HashMap`과 `HashSet`은 순서를 보장하지 않는다.
- 배열의 길이는 `length`, 문자열의 길이는 `length()`, 리스트의 크기는 `size()`이다.
- 비교자에서 `a - b` 대신 `Integer.compare(a, b)`를 사용하면 오버플로를 피할 수 있다.
- 객체 비교에서는 `equals`, 정렬 기준에서는 `compareTo` 또는 `Comparator`를 사용한다.

        StringBuilder answer = new StringBuilder();
        answer.append(n).append('\n');
        System.out.print(answer);
        // 입력받은 n을 한 줄에 출력한다.
    }
}
```

## 17. 진법 변환

### 10진수에서 다른 진법으로 변환

`Integer.toBinaryString`, `toOctalString`, `toHexString`은 10진수 정수를 각각 2진수, 8진수, 16진수 문자열로 변환한다.

```java
int number = 10;

String binary = Integer.toBinaryString(number); // 10진수 10을 2진수 문자열로 변환
String octal = Integer.toOctalString(number);   // 10진수 10을 8진수 문자열로 변환
String hex = Integer.toHexString(number);       // 10진수 10을 16진수 문자열로 변환

System.out.println(binary); // 1010
System.out.println(octal);  // 12
System.out.println(hex);    // a
```

### 다른 진법에서 10진수로 변환

`Integer.parseInt(문자열, 진법)`은 해당 진법의 문자열을 10진수 정수로 변환한다.

```java
int decimalFromBinary = Integer.parseInt("1010", 2); // 2진수 1010을 10진수로 변환
int decimalFromOctal = Integer.parseInt("12", 8);     // 8진수 12를 10진수로 변환
int decimalFromHex = Integer.parseInt("a", 16);       // 16진수 a를 10진수로 변환

System.out.println(decimalFromBinary); // 10
System.out.println(decimalFromOctal);  // 10
System.out.println(decimalFromHex);    // 10
```

위 코드에서 첫 번째 인자는 변환할 문자열이고, 두 번째 인자는 문자열이 현재 표현된 진법이다.

### 원하는 진법으로 변환

`Integer.toString(정수, 진법)`을 사용하면 10진수 정수를 원하는 진법의 문자열로 바꿀 수 있다.

```java
int number = 42;

String binary = Integer.toString(number, 2); // 101010
String baseFive = Integer.toString(number, 5); // 132
String baseSeven = Integer.toString(number, 7); // 60

System.out.println(binary);
System.out.println(baseFive);
System.out.println(baseSeven);
```

반대로 원하는 진법의 문자열을 10진수로 바꿀 때는 `parseInt`를 사용한다.

```java
int number = Integer.parseInt("101010", 2);
System.out.println(number); // 42
```

### 2진수 문자열을 한 자리씩 처리하기

```java
String binary = "1011";
int decimal = 0;

for (char bit : binary.toCharArray()) {
    decimal = decimal * 2 + (bit - '0');
}

System.out.println(decimal); // 11
```

현재까지의 값을 2배로 만든 뒤 다음 비트를 더하는 방식이다.

### 10진수를 2진수로 직접 만들기

```java
int number = 13;
StringBuilder binary = new StringBuilder();

while (number > 0) {
    binary.append(number % 2); // 마지막 이진수 자리 추가
    number /= 2;                // 다음 자리를 계산
}

binary.reverse();
System.out.println(binary); // 1101
```

실제 코딩 테스트에서는 내장 함수가 간단하고 안전하므로 `Integer.toBinaryString`과 `Integer.parseInt`를 우선 사용하면 된다.
